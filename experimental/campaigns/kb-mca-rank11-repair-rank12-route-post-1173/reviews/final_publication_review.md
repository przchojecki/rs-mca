## One-PR recommendation

One stacked successor PR is the correct publication unit.  The inline
shortening theorem, uniform rank-one cap, raw-low recurrence, rank-eleven
payment, and immediate single-threshold wall form one indivisible proof and
boundary packet.  Splitting the method wall into another PR would obscure
why the same verified mechanism stops at rank twelve; combining unrelated
rank-twelve experiments would overbroaden the result.

The PR should initially be **draft** because #1160 and #1173 remain open and
the final mathematics/certificate/manifest gates are separate.  Before it is
marked ready, its description should include the exact final head and review
range

```text
2788d5ec3fb4b1d6f9c43a58a86ec2381e5f6804..<final-head>
```

and explicitly say that integration requires both #1160 and #1173 (or an
integration commit containing them).  The current “release gate requires”
wording is honest for a draft and must be replaced by actual PASS claims only
after the final sealed tree is replayed.
