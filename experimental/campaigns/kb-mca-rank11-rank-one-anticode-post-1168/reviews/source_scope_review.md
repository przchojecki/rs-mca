# Source-scope review

Status: **GREEN after repair.**

The first draft attempted to invoke the parent complete correction-ray
theorem directly in the fixed-right-factor branch. That invocation was too
broad. The parent theorem is proved in a spread-core context where the
coordinate error polynomials are nonzero; a base minimizing pair can instead
leave a universal set on which both its affine error and the correction
direction vanish identically.

The final packet does not use that unsupported import. It defines the
universal core \(U\), keeps its full legal range \(0\le |U|\le K-1\), and
proves a separate affine-degree-one clone count. The exact scan of all
`1,048,576` core sizes gives the uniform bound `8,147,918`.

The fixed-left proper-space argument is unaffected: its affine hyperplane
double count permits identically zero or dependent coordinate equations by
routing any non-singleton intersection to the nonproper
positive-dimensional terminal.

No source-scope overreach remains in the frozen claim.
