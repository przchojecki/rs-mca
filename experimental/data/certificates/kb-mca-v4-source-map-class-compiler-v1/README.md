This directory contains the exact certificate for an abstract
first-match/deduplication compiler, fixed six-coordinate slope encoding, and
collective 68/69 packet-threshold route cut.

Replay from the repository root:

```bash
python3 experimental/scripts/verify_kb_mca_v4_source_map_class_compiler_v1.py --check
python3 experimental/scripts/verify_kb_mca_v4_source_map_class_compiler_v1.py --tamper-selftest
python3 experimental/scripts/verify_kb_mca_v4_source_map_class_compiler_v1_independent.py
sage experimental/scripts/verify_kb_mca_v4_source_map_class_compiler_v1.sage
```

The packet accepts only `ABSTRACT_REGRESSION_ONLY` records. It distinguishes
extension-field slopes, projective residue directions, and opaque declared
rational source-map classes. It does not validate source equations, branch or
owner membership, packet exhaustiveness, or a deployed selector. Imported
exclusions are registry entries, not charged-slope fixture records. It books
no charge and leaves the KoalaBear row open.
