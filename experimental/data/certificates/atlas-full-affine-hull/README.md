# Atlas full affine-hull certificate bundle

Author: Manuel E. Rey-Álvarez Zafiria

This directory contains:

- the exact M31 rank-two fixture and its 14+2 pencil certificate;
- primary and independent support certificates for supports 2 through 8;
- primary and independent dense certificates for supports 9 through 16;
- rational-bidegree, Cauchy, and Schur-power route-cut certificates;
- the full 65,535-support affine-hull synthesis.

Run the synthesis command in `REPLAY.txt` for the short terminal check.
Regenerating the dense C++ reports is substantially more expensive and is
listed separately. C++ regeneration requires an OpenMP-capable compiler.
