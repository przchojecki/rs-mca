# Subgroup Syndrome Section for the Pinned M3 Row

Status: PROVED / AUDIT.

For the pinned row

```text
C = RS[F_17^32,H,256],    |H|=512,
```

the M3 regular-window syndrome length is `n-k=256`.  Use the weighted syndrome
map

```text
Syn(y)_m = (1/512) sum_{x in H} x*y(x)*x^m,    0 <= m < 256.
```

For an arbitrary syndrome vector `s`, define

```text
y_s(x) = sum_{a=0}^{255} s_a x^(-a-1).
```

Then

```text
Syn(y_s)_m
  = (1/512) sum_a s_a sum_{x in H} x^(m-a)
  = s_m.
```

The only input is that `H` is generated by an exact order-512 element, so
`sum_H x^e` vanishes for every nonzero exponent `e` with `|e|<256`, while the
zero-exponent sum is `512`, invertible in characteristic `17`.

The replay packet is:

```text
experimental/data/certificates/subgroup-syndrome-section/
  subgroup_syndrome_section_certificate.json
```

This removes a possible row-data ambiguity for M3 packets: every length-256
syndrome pencil has explicit received-line values on the pinned subgroup row.
It does not classify the roots of those pencils or prove an MCA safe-side
bound.
