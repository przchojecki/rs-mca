## 2. Exact abstract first-match lemma

Let \(X\) be a finite collection of abstract records. Assume syntactically:

1. every record has the same declared line, source, selector, and context;
2. every slope has one six-coordinate value, one graph-record identifier, one
   projective residue direction, and one declared rational source-map class;
3. every declared owner target contains the same line and slope coordinates
   and the same graph-record identifier as its record;
4. every slope has a nonempty set of declared owner candidates; and
5. the ten-owner order above is fixed.

For a supplied slope \(\eta\), let \(I(\eta)\) be the least owner index among
its declared candidates. Then

\[
C_i=\{\eta:I(\eta)=i\}
\]

is a disjoint and exhaustive partition of the distinct supplied slopes, and

\[
\sum_i |C_i|
=
\bigl|\{\eta:\eta\text{ occurs in }X\}\bigr|.
\]

### Proof

Each supplied slope has a nonempty finite candidate set, so its least index
exists and is unique. Grouping records by the six-coordinate slope before
selecting that index removes duplicate witnesses. The charged grouping key
does not contain the residue-direction key or rational-map identifier, so
neither diagnostic projective normalization nor a shared direction collapses
two distinct slopes. The target-coordinate and graph-record comparisons
prevent syntactic transport between different records. \(\square\)

This proof is conditional on the truth of the supplied mathematical
predicates. The verifier checks their shape and identity targets; it does not
prove them.

## 3. Collective packet-threshold lemma

Fix one declared residue-line and packet identifier. Suppose the packet is
declared exhaustive. Let \(\mathcal M\) be the set of distinct declared
rational source-map class identifiers appearing in the packet. The compiler
derives exactly one of

\[
|\mathcal M|\le68
\quad\text{or}\quad
|\mathcal M|\ge69.
\]

It assigns the conditional cap-68 terminal only in the first case, and the
explicit unpaid primitive terminal in the second. There is no per-slope
`CAP68` flag and no way for 69 distinct class identifiers in one packet to
receive the cap-68 terminal.

This is an exact finite-set dichotomy, not a proof that a deployed packet is
exhaustive or that its identifiers are genuine rational source-map classes.
